## Gaps and blockers
- Windows-only dependency: `@node-rs/argon2-win32-x64-msvc` blocks plain `npm ci` on Linux. Local installs use `npm_config_nodedir=/usr/local npm ci --force`. The Windows build still requires a Windows runner.
- Physical printer, DPI and installer behaviour cannot be tested in this sandbox; they must be validated on a Windows machine.
- Playwright E2E requires an Electron binary and display; the latest attempt failed before launch because the binary was absent and download failed. No E2E scenario has passed in this session.
